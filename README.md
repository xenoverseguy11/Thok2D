## A game engine easy to use yet so powerful.

# WHAT DOES IT INCLUDE??
this is a barebones engine, meaning its entirely code driven, no UI, no drag and drop.

-**WINDOW**: Complete ✅
-**GAME LOOP**: Complete ✅
-**AUDIO WRAPPER**: Complete ✅
-**SPRITES**: Working on it ℹ️
-**PHYSICS**: Not complete ❌
-**TEXT WRAPPER**: Not complete ❌
-**INPUT WRAPPER**: Not complete ❌
-**TILE MAP** Not complete ❌
- In future, there will be more features. once I finish this I will move to make Thok3D!



# WHAT DEPENDENCIES/LIBRARY DOES IT NEED?:

**Visual Studio 2022 and newer**: sorry linux users.

-as of now it needs:
**SDL2**: for window and the renderer.
**SDL_Mixer** for audio.

-in future it might need:
**GLM**: for the math(like vectors)
**SDL_TTF**: for fonts

I will decide later.
